# 몹 애니메이션 추가 방법

**코드는 건드리지 않아도 됩니다.** 클립을 넣고 컨트롤러에 파라미터·상태만 추가하면 자동으로 재생됩니다.

`EntityViews.ApplyOptionalParams`가 개체 생성 시 애니메이터 파라미터를 조사해, **있는 것만** 구동합니다.
없는 파라미터에 값을 쓰면 Unity가 매 프레임 경고를 쏟기 때문에 이렇게 만들어 두었습니다.

---

## 현재 상태 (2026-07-22)

| 몹 | 컨트롤러 | 보유 클립 | 없는 것 |
|---|---|---|---|
| 돌진(핑키) | ObsidianSentinelController | Walk · Run · **Jump** | Hurt · Death |
| 근접(그런트) | FootSoldierController | Walk · Attack | **Jump** · Run\* · Hurt · Death |
| 원거리(솔저) | MonolithSentinelController | Walk · Aim | **Jump** · Hurt · Death |
| 공중(카코) | **없음** | — | 전부 |

\* `FootSoldier_Run.fbx`는 **이미 임포트돼 있는데** 컨트롤러에 Run 상태가 없어 놀고 있습니다.
  `MonolithSentinel_AimTurn.fbx`도 마찬가지입니다.

---

## 추가 절차

### 1. 클립 임포트
```
Assets/_Project/Art/<몹폴더>/<몹>_Jump.fbx
```
Rig 설정은 같은 폴더의 기존 FBX(예: `FootSoldier_Run.fbx`)와 **동일하게** 맞추십시오.
`Apply Root Motion`은 **꺼야 합니다** — 켜면 루트 모션 드리프트로 몹이 바닥에 가라앉거나 회전이 누적됩니다
(이 프로젝트에서 이미 한 번 겪은 문제입니다. `EntityViews`의 `MeleeFeetLift` 주석 참고).

### 2. 컨트롤러에 파라미터 + 상태 + 전이 추가

**파라미터 이름은 정확히 이대로** 지어야 코드가 잡습니다 (전부 `bool`):

| 파라미터 | 상태 | 코드가 넣는 값 |
|---|---|---|
| `IsAirborne` | Jump | `!e.grounded` — 공중에 뜬 동안 true |
| `IsRunning` | Run | 속도 ≥ `RunThresholdSpeed`(4.2 m/s) |
| `IsHurt` | Hurt | `stunTicks > 0` — 피격 경직 동안 |
| `IsDead` | Death | `!e.alive` |

**전이 조건은 `ObsidianSentinelController`의 Jump를 그대로 베끼면 됩니다:**
```
Walk/Run → Jump   : IsAirborne == true    (Has Exit Time 끔, Duration 0.15)
Jump → Run        : IsAirborne == false && IsCharging == true
Jump → Walk       : IsAirborne == false && IsCharging == false
```

### 3. 확인
```
solo grunt
animcaps      ← 어떤 파라미터가 잡혔는지 표시 (O / ·)
anim grunt    ← 실시간 상태·파라미터 값 관찰
```

`animcaps`에서 `O IsAirborne` 으로 나오면 연결된 것이고, 다음 Play부터 바로 재생됩니다.

## 클립이 없는 동안은

절차 애니메이션이 대신합니다 — 코드에서 자세를 만들어 얹습니다.

| 레이어 | 콘솔 | 내용 |
|---|---|---|
| 텔레그래프 | `tele` | 공격 예비 · 돌진 준비 · 차징 · 피격 반동 |
| 이동·상황 | `mv` | 급선회 · 가감속 · 경사 · 휘청 · 반동 · 붙잡힘 · 저체력 · 공중 뱅킹 |
| 녹슨 관절 | `rust` / F9 | 관절별 고착 + 스프링(삐걱거림) |

**클립이 생기면 겹치는 항목만 꺼주십시오.** 예를 들어 진짜 Hurt 클립이 들어오면
`tele hit 0` 으로 절차 피격 반동을 끄면 됩니다.

---

## 주의

- **`Apply Root Motion`은 항상 끄십시오.** 이동은 Sim이 계산하고 뷰는 따라가기만 합니다.
- 클립은 **제자리 모션**이어야 합니다. 이동 속도에 맞춘 재생 배속은 코드가 자동으로 맞춥니다.
- 공격 모션은 **배속을 건드리지 않습니다**(판정 타이밍과 어긋나면 안 되므로).
