## 0. 목표

맵은 **흑백**, 강조색 2개만 살린다 — **초록 = 해킹 / 빨강 = 위험**(§7).
색이 아니라 **명도·러프니스**로 재질을 읽게 만든다.

## 1. 방식 비교 (복구 난이도 기준)

| | 방식 | 복구 | 애셋 수정 | LED·UI 색 보존 | 블룸 | 작업량 |
|---|---|---|---|---|---|---|
| **A** | **후처리 채도 제거**<br>Volume + Color Adjustments −100 | ⭐ 슬라이더/오브젝트 토글 | 없음 | ❌ 같이 흑백 | ✅ | 5분 |
| **B** | **셰이더 교체**<br>`GreyLit`으로 머티리얼 shader만 변경 | ⭐ shader 필드 되돌림<br>(목록 기록 → 일괄 복구) | 머티리얼 파일<br>(텍스처 무손상) | ✅ 안 바꾸면 컬러 | ✅ | 1시간+ |
| **C** | **레이어 분리 후처리**<br>커스텀 렌더 피처 | ⭐ 피처 체크 해제 | 없음 | ✅ | ✅ | 반나절+ |
| **D** | **텍스처 오프라인 변환**<br>albedo PNG를 그레이스케일로 | ❌ **백업 없으면 불가** | 파일 덮어씀 | ✅ | ✅ | 30분 |

**제외**: "컬러 오브젝트를 후처리 뒤에 렌더"(내장 RenderObjects) — 쉽지만 **그 레이어가 블룸을 못 받아 LED가 안 빛난다.** 치명적.

**D는 쓰지 않는다** — 복구 불가라 이 프로젝트의 원칙(복구 용이)에 어긋난다.

## 2. 확정 방침 — 단계적 전환

### 지금(1단계): **A 후처리**

- 색으로 남길 것(이펙트·발광·UI)이 **아직 존재하지 않는다** → A의 유일한 단점이 지금은 발생하지 않는다.
- 애셋을 하나도 안 건드리므로 **값 튜닝에만 집중**할 수 있다.
- 애셋 출처가 제각각(TallCity·Remesh·Turret·CCTV·Robot1F·Precog 이식분·AI 모델)이라, 지금 전부 셰이더 교체하면 **누락이 생겨도 확인할 방법이 없다** — 화면이 이미 흑백이라 교체 여부가 눈으로 구분되지 않는다.

### 나중(2단계): **B 셰이더**로 전환

**전환 시점**: LED·UI·이펙트 등 **색으로 남길 것이 처음 생길 때.**

그 시점엔 작업 방향이 뒤집혀 훨씬 쉬워진다:

> 전체를 흑백으로 바꾸는 게 아니라 → **색으로 남길 소수만 지정**

대상이 수십 개가 아니라 몇 개로 줄고, 검증도 "초록 LED가 초록으로 보이나" 한 줄이면 된다.

### 전환 절차 (2단계 착수 시)

1. `GreyLit` 셰이더 제작 — URP Lit과 동일 동작 + **샘플한 albedo의 채도만 제거**. `_Desaturation` 프로퍼티를 두고 **전역 셰이더 프로퍼티**(`Shader.SetGlobalFloat`)로 구동 → **슬라이더 하나로 모든 월드 재질** 조절(지금 후처리와 사용감 동일).
2. 환경·프롭 머티리얼을 폴더 단위로 일괄 교체. **교체 전 shader 목록을 JSON으로 기록** → 일괄 복구 가능.
3. 색으로 남길 것은 **교체하지 않는다**(그게 곧 예외 지정).
4. 후처리 채도를 0으로 되돌리고 B만 남긴다.
5. 절차 재질(`TriplanarGrunge`)은 **이미 회색만 출력**하므로 교체 불필요.

> ⚠️ Normal / Metallic / Roughness / AO 맵은 **절대 건드리지 않는다**(아트 노트 경고). 흑백화는 **albedo에만**.

## 3. 조명 원칙 — "빛을 없앤다"의 함정

**금속은 albedo가 아니라 환경 반사에서 밝기를 얻는다.** 그래서 아래 셋을 동시에 0으로 만들면 직접광이 닿아도 **검게 남는다**:

```
reflectionIntensity = 0  +  skybox = null  +  ambient ≈ 0
```

실제로 이 세팅에서 절차 재질(metallic 0.85)이 완전 검정이 됐다. 아트 노트 "함정 3"이 경고한 그대로다.

**원칙**
- ambient·reflection은 **무채색으로** 만드는 것이지 **0으로 만드는 게 아니다.**
- 어둡되 0은 아닌 상태(대략 ambient 0.08~0.15, reflection 1.0)가 출발점.
- 필요하면 **Reflection Probe를 배치·베이크**해 금속에 제대로 된 반사를 준다(정석).
- **하이라이트를 없애면 안 된다** — 흑백에서는 반사 하이라이트가 "이게 금속이다"를 알려주는 거의 유일한 단서다. 크기·세기를 잡는 것이 목표.

## 5. 절차 재질 (`TriplanarGrunge`)

`Assets/_Project/Shaders/TriplanarGrunge.shader` + `Assets/_Project/Art/Mat_FactoryGrunge.mat`

**왜 만들었나**: AI 생성(Tripo) 메시의 **UV가 망가져 있다** — UV 면적 : 3D 표면적 = **1 : 7,900**. UV 껍질이 면적 없는 슬리버라 **어떤 텍스처도 붙지 않는다**(베이크한 노멀맵 포함). UV 재전개는 모델 3개 × 100여 파트라 비용이 크다.

**해결**: UV를 아예 쓰지 않고 **월드 좌표 기반 절차 생성**.
- fbm 그런지(명도 얼룩) + **높이 기반 녹** + **윗면 먼지** + **아랫면 캐비티**
- 노이즈 기울기로 **노멀 퍼터베이션**(탄젠트·노멀맵 불필요)
- 녹·먼지 부위는 **거칠고 metallic 낮게** ← 폐공장 질감의 핵심
- 애초에 회색만 출력 → 2단계 전환 시에도 교체 불필요

**주의**
- 녹이 **월드 Y 절대 높이** 기준 → 오브젝트를 옮기면 녹 분포가 따라 변한다. 로컬 기준이 필요하면 수정.
- **모바일 성능**: 픽셀당 fbm을 4회(요철 기울기) 평가. 무거우면 `_BumpStrength = 0`으로 두면 그 4회가 사라진다.

## 6. 현재 씬 상태 (HackSandbox) + 복구 값

**적용됨**
```
ambientMode = Flat,  ambient = 0.02 (무채색),  skybox = 없음,  reflectionIntensity = 0
Directional Light = 비활성화(삭제 아님)
[TestLights] = 스포트라이트 (확인용)
[GreyscaleTest] = Volume, 채도 -100 / 대비 +10 / 블룸(threshold 1.05, intensity 1.2)
Main Camera = clearFlags SolidColor(검정), renderPostProcessing = ON
```

**⚠️ 위 ambient 0.02 / reflection 0 은 §3의 함정에 해당한다 — 튜닝 대상.**

**복구용 원래 값**
```
ambientMode         = Skybox
ambientLight        = RGBA(0.212, 0.227, 0.259, 1)
ambientSkyColor     = RGBA(0.212, 0.227, 0.259, 1)
ambientEquatorColor = RGBA(0.114, 0.125, 0.133, 1)
ambientGroundColor  = RGBA(0.047, 0.043, 0.035, 1)
skybox              = Default-Skybox
reflectionIntensity = 1
Main Camera         = clearFlags Skybox, renderPostProcessing = False
```

복구는 전부 **삭제가 아니라 비활성화/값 변경**이라 되돌리기 쉽다.

## 7. 미확정 (F2로 판단할 것)

- [ ] 환경광 밝기 / 반사 강도 — "어둡되 형태가 읽히는" 지점
- [ ] 조명 세기·각도·개수 (현재 스포트 900/500은 과함 → 하이라이트 블로우아웃)
- [ ] 채도(−100 고정 여부) · 대비 · 노출
- [ ] 블룸 문턱·세기
- [ ] 절차 재질 metallic (0.85는 어두운 씬에서 과할 수 있음)
- [ ] Reflection Probe 도입 여부
- [ ] 2단계 전환 시점 (LED·UI 등장 시)

## 8. 겪은 함정 기록

1. **환경광·반사를 0으로 → 금속이 완전 검정.** 무채색으로 만드는 것과 0으로 만드는 것은 다르다(§3).
2. **`GameObject.Find`는 비활성 오브젝트를 못 찾는다** — 꺼둔 조명을 다시 켜는 코드가 동작하지 않았다. `FindObjectsByType(..., FindObjectsInactive.Include)` 사용.
3. **`VolumeProfile.Add<T>()`만으로는 에셋에 저장되지 않는다** — `AssetDatabase.AddObjectToAsset`으로 서브에셋 등록까지 해야 한다. 이걸 빠뜨려 **후처리가 적용된 줄 알았으나 실제로는 컴포넌트 0개**였다.
4. **Play 모드에서 씬 변경은 정지 시 되돌아간다** — 배치한 모델이 사라졌다. 씬 작업 전 Play 상태 확인 필수.
5. **AI 생성 메시의 UV는 신뢰할 수 없다** — 범위(0~0.85)만 보고 정상으로 판단하면 안 되고 **면적**을 봐야 한다.
