## 0. 막 구성 변경 (4막 → 2막)

- **1막 (잠입 퍼즐)**: 스테이지 **4개**를 통과해 최종 제어실로.
- **2막 (추격·탈출)**: 보스 각성 → 왔던 길 **역순**으로 도주. 각 스테이지 **입구(좁음)** 위에 유압프레스가 있고, 보스가 입구에 머리를 박아 끼면 프레스로 찍는다. **총 4회** → 머리가 점점 찌그러지다 4회째 완전 납작·파괴 → 탈출·엔딩.

기존 3·4막(복귀 퍼즐, 반전·2차 추격)은 **삭제**. §12.2의 "3막 복귀·4막 새 길"도 근거 소멸.

## 1. 핵심 루프 — 입구 1개 = 1사이클

```
① 역순 도주 → 좁은 입구 진입
② 보스가 입구에 머리를 쾅 박고 끼임(Wedged, T초 고정)
③ 프레스 바라봄 → Space 홀드 → 점 패턴(5선) → 장악
④ 좌클릭 = 신장 → 압착. 머리 단계 +1
⑤ 보스 이탈·후퇴 → 추격 재개, 플레이어는 다음 스테이지로
```

- **보스 해킹(구 §11.3) 삭제.** "시간 벌기"는 물리적 끼임이 대신한다. 얼굴을 자주 보여주는 역할은 프레스 4회가 대신한다.
- ③④는 1막에서 배운 조작 그대로 — 새 문법 0개, 압박만 추가.
- **실패 처리 미정**: 끼임 시간 안에 못 찍었을 때 (가) 재돌진 허용 / (나) 1회 성공 필수. → 결정 대기.

## 3. 머리 압착 — 철판 파츠 포즈 4단계

- 모델 스왑 대신 **모델 1개**: 머리를 이루는 철판 부품들의 { pos, rot, scale } 스냅샷을 단계 0~4로 저장, `Stage(n)` 호출 시 0.15초 보간. 프레스가 가리는 동안 일어나므로 튀어도 안 보인다(§11.2 원리 유지).
- 눈알은 분리 오브젝트 — 단계마다 바깥·앞으로 밀려 넙죽이 눈이 된다.
- 4단계에서만 파편 스왑 + 눈알 팝아웃.
- 포즈 저장 도구: `PoseSnapshotTool`/`PoseJsonTool` 계열 재사용(대상만 본→머리 파츠).

## 4. 추격 이동·손 짚기 (파괴 축소 — 2026-07-30 개정)

- **`BossHandhold`** 마커를 벽에 직접 배치: `side`(L/R/Any). 없으면 옆벽 레이캐스트 폴백.
- **`BossChase`**: 전진하며 다음 짚을 곳을 좌우 번갈아 고른다. **짚은 손은 월드에 고정**되고 몸이 그리로 밀려간다. 팔이 `releaseExtension` 이하로 접히면 떼고 다시 앞을 짚는다.
- **짚는 곳은 앞으로 멀리.** 복도 폭(≈48m)에 비해 팔이 길어(어깨→벽 14m vs 팔 32m) 바로 옆을 짚으면 팔꿈치가 112도 접혀 메시가 뭉개진다. 어깨~지점 거리가 팔 길이의 `reachUse`가 되도록 앞 성분을 역산해 **앞 27~29m / 옆 13~15m** 지점을 짚는다.
- **팔꿈치 방향은 `elbowHint`가 소유한다.** 2본 IK의 남은 자유도 하나를 손바닥 정렬에 주면 팔꿈치가 안쪽으로 오므라든다. 벽을 짚는 연출에서는 팔꿈치가 바깥으로 벌어져야 하므로 이쪽이 우선(`alignStrength = 0`). 손바닥은 `rollOffset`으로 따로 맞춘다.
- 손등으로 짚는다(`braceWithBackOfHand`). 손바닥을 벽에 붙이면 어깨를 크게 비틀어야 한다.
- IK 솔버는 프로젝트 기존 자체 구현(`HandIK`/`SpiderLegs`의 FromToRotation 2본 솔버) 계열을 재사용 — 외부 패키지(Animation Rigging) 도입 없이 간다.

### 4.1 파괴 — **짚는 곳 파괴는 폐기**

- ~~짚는 손 = 부서지는 곳~~ → **구현하지 않는다.** 벽을 짚을 때마다 조각을 부수는 것은 만들 것에 비해 얻는 게 적다.
- **남기는 것은 "정면에 있는 것을 부수며 온다"뿐이다.** 보스가 지나가는 앞쪽 장애물만 파괴한다.
- 그 정면 파괴는 **물리 베이크**로 굽는다(§12.0) — 결과가 항상 같아 타이밍이 프레임 단위로 고정되고, 런타임엔 재생만 한다.
- 잔해는 플레이어와 **충돌하지 않는다**(§12.1 유지).
