## 1. 발견된 문제 (심각도 순)

### ① Static 플래그가 전부 0

```
StaticEditorFlags 오버라이드 0개 / 씬 GameObject 24개 전부 0
m_OcclusionCullingData = 0  (베이크 없음)
```

**핵심은 배칭이 아니라 오클루전 컬링이다.** Static은 세 기능의 스위치이고 값어치가 다르다.

| 기능 | 이 씬에서 |
|---|---|
| **오클루전 컬링** | ★★★ 벽 뒤 수백 개를 매 프레임 그리는 중. Static 없이는 켤 수조차 없다 |
| 라이트맵(Contribute GI) | ★★ 실시간 라이트를 줄이는 전제 |
| 정적 배칭 | ★ **여기선 오히려 손해 가능** — 같은 메시를 328번 복제해 메모리에 올린다. 인스턴싱이 낫다 |

### ② 실시간 그림자 라이트 3개

셋 다 `lightmapping=4`(Realtime) + `m_Shadows.m_Type=2`(Soft).
그림자 캐스팅 라이트 하나당 **씬 전체를 라이트 시점에서 다시 그린다.** ×3 ×2눈.

### ③ GPU 인스턴싱 전부 꺼짐

머티리얼 27개 **전부 `m_EnableInstancingVariants: 0`**.
`holder 04` 328개처럼 동일 메시 반복이 많아 **효과가 가장 확실한 항목**.

### ④ 메시콜라이더 460개

`holder`·`wall` 같은 상자형에 메시콜라이더. 쿠킹 비용·메모리·쿼리 비용이 박스보다 크다.
`AutoTraversal`이 매 프레임 레이·스피어캐스트를 쏘므로 이동 판정에서 직접 손해.

### ⑤ 기타

- `generateSecondaryUV: 0` — 라이트맵 구우려면 켜야 함
- `boat.FBX` 2.2MB 임포트돼 있으나 씬에서 미사용
- 카메라 `far clip = 1000` — 도시 스케일 대비 과할 수 있음

## 2. 문제가 **아닌** 것 (확인됨)

### 금속 반사 재질 — 의도대로 두면 된다

Metallic/Smoothness가 높아도 URP Lit의 픽셀 비용은 사실상 동일. 드로우콜·패스 안 늘어남.
반사가 비싸지는 건 **실시간 리플렉션 프로브**뿐인데 Stage1에는 **프로브 0개**.
베이크 프로브를 넣어도 런타임 비용 없음(메모리만) — 오히려 [흑백_아트_계획](흑백_아트_계획.md) §3의 "금속이 검게 죽는" 문제의 정석 해법.

## 3. 손전등 — 사거리가 아니라 그림자가 변수

| 안 | 비용 | 대가 |
|---|---|---|
| A. 사거리 길게 + **그림자 끔** | 중간 | 벽 뚫고 빛이 샘 |
| B. 사거리 길게 + **그림자 저해상도**(256~512) | 중간~높음 | 그림자 뭉개짐(어두운 씬이라 티 덜 남) |
| C. 사거리 길게 + **감쇠 강하게** | 중간 | 실질 사거리는 짧아짐 |

- 라이트맵을 굽고 Static을 걸어도 **실시간 손전등은 그 위에 그대로 더해진다** — 충돌하지 않는다.
- URP는 오브젝트당 추가 라이트 개수 제한(기본 4)이 있어, 상시 켜진 손전등이 슬롯 하나를 점유한다.
- 잠정 방향: **B + C**, 그리고 **기존 실시간 그림자 라이트 3개 정리**.
- 벽이 두껍고 완전히 닫힌 구조면 A도 가능 → **스테이지 완성 후 판단**.
- 참고: MINDHEXER 쪽 콘솔에 `[Flashlight]` 오브젝트에 Light가 없다는 예외가 계속 뜬다(만들다 만 상태).

### 그림자가 하는 일 (판단 근거)

1. **접지** — 물체가 바닥에 붙었는지 떠 있는지. 발판 퍼즐에서는 곧 조작 정보
2. **형태** — 파이프·격자가 겹친 공장에서 요철을 드러냄
3. **광원 방향** — 없으면 손전등이 "빛을 쏜다"가 아니라 "벽에 페인트칠"로 보임
4. **빛샘 차단** — 실무에서 제일 큼. 복도 구조에서 즉시 티가 남

**흑백이라 가중치가 더 크다.** 색이 없으면 명암이 정보의 거의 전부([기초_설계안](기초_설계안.md) §7).

### 그림자의 대체 수단

| 방법 | 런타임 비용 | 커버 범위 |
|---|---|---|
| **라이트맵 베이크** | **0** | 안 움직이는 것끼리의 그림자 전부 |
| **SSAO** | 낮음(1패스) | 접지·틈새 어둠 (위 2번을 싸게 대신) |
| 블롭 섀도우 | 거의 0 | 접지만. 캐릭터용 |
| 실시간 그림자 | 높음 | 전부 |

> **정석**: 안 움직이는 도시는 라이트맵으로 구워 그림자를 공짜로 얻고, 실시간 그림자는 **손전등 하나에만** 쓴다.
> 지금 Stage1은 정반대 — 굽지 않고 실시간 그림자 3개. **가장 비싼 방법으로 가장 안 움직이는 것을 그리고 있다.**
