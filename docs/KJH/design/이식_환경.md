# MINDHEXER 이식 환경 — PrecogPrototype 전수 조사

> KJH 개인 문서. 상태: **초안**. shared 승격 전.
> 이전 프로젝트 `D:\Dev\madcamp\26s-w3-c3-04\PrecogPrototype`(Unity 6.2)를 전수 조사해, MINDHEXER로 **가져올 것 / 버릴 것**을 판단한 결과다.
> 원본 코드 경로는 각 항목에 명시. 이식 **순서·방법**은 별도 협의 후 확정한다(이 문서는 "무엇을·왜"까지).

## 0. 대전제

- **Unity 6.2 → 2022.3**: ProjectSettings·URP 애셋·패키지는 **복사 불가(2022.3에서 재생성)**, **코드·커스텀 셰이더(URP HLSL)는 대체로 그대로 컴파일**.
- **PC 먼저 → VR 나중**([기초_설계안.md](기초_설계안.md) §10): IMGUI·1인칭 카메라·뷰모델·ScreenFx 등 "VR이라 안 됨"이던 것도 **PC 단계엔 유효**. VR 이식 단계에서만 WorldSpace UI·Cinemachine 3→2·멀미요소 절제.
- **물리 모델 이원화**: 캐릭터(플레이어·경비병) 이동 = **kinematic CharacterMotor 재사용** / 해킹한 **물체** 조종 = **PD·6DoF(별도 설계)**.
- 소스에 **XR/Cardboard 플러그인 전무** → VR 세팅은 참고 없음, SYB 쪽 신규 구축.

이식 등급: **직접**(코드/셰이더 그대로) · **수정**(트리거·필드 교체) · **개념만**(접근법만 참고) · **불가/불필요**(안 가져옴).

## 3. 별도 — 복사 불가·재생성 (설정, 버림 아님)

프로젝트 설정 전부(Unity 6.2 ↔ 2022.3 비호환) → **2022.3에서 신규 작성**, 값·튜닝 방향만 참고.
- 채택 값: Linear 색공간·IL2CPP·ARM64·minSDK26·모바일 품질 티어.
- **VR 조정**: Landscape 고정 · HDR off 검토 · MotionBlur/Vignette 제거 · **RP 애셋에 Opaque/Depth Texture 켜기**(RadialInvert 등 포스트이펙트 동작 조건).
- 제거: PPv2·`UNITY_POST_PROCESSING_STACK_V2` define·visualscripting·multiplayer.center·collab-proxy.
- 추가 필요: `com.unity.xr.management` + Google Cardboard XR Plugin.
