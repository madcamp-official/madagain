### 3. Precog 엔진 통째 제거 (ADR-0002)
- 예측 코드가 `Main.cs`·World 시뮬에 용접 → **Precog 엔진 전체를 들어냄.** 우리 코드는 무의존이라 그대로 작동.
- VR 작업(`Main.cs`의 XR 리그)은 **GameBoot으로 이식**(C 작업 유실 방지).
- 삭제: Sim·Bridge·Prediction·Tests·View precog 전부·Main·전투·타이틀·웨이브·카타나·precog 에디터툴 (~700파일)
- 유지: 우리 코드 + 독립 에디터 툴 13 + 셰이더/아트 자산 + `VrMode`·`VrHudSpace`·`IRunResettable`
- 커밋: `4ac48c4`(baseline·C보존) `b0d28a0`(카타나자산) `a640a4a`(GameBoot+게이트) `f790dc5`(VR이식) `21ab9cd`(엔진삭제 444) `e025e93`(씬·프리팹 254) `896c817`(완료)
- **검증**: `Game.View.Main` 타입 자체가 없음, 콘솔 0에러/경고, HackSandbox 정상 렌더.
- 상세·복구: `docs/KJH/decisions/0002-precog-purge.md`

### 4. GameBoot — MINDHEXER 자체 부트스트랩
- `View/Bootstrap/GameBoot.cs`: 씬에 `[GameBoot]` 하나로 카메라+해킹 구성. **`VrMode.Enabled`면 XR 리그+VrHudSpace, 아니면 PC(FreeLook).** 예측/vcam 의존 없음.
- Precog `Main`·`TitleScreen`은 GameBoot 존재 시 자동부팅 스킵(가드) — 삭제 전 임시 게이트였고, 지금은 precog 자체가 삭제됨.

### 5. 2-카피 MCP 워크플로 (ADR-0003)
- `MINDHEXER/`(git 정본) + `MINDHEXER-forDev/`(gitignore 미러). **같은 프로젝트 카피 2개** — MCP 인스턴스 2개로 병렬 분업.
- 동기화 스크립트: `tools/sync-to-fordev.sh`(받아오기, git archive) · `tools/merge-from-fordev.sh`(합치기, 복사+git 검토)
- 커밋: `ff97fd9`·`8b44115`·`575ecb2`. forDev 초기 동기화 완료(clean 미러 확인).
- 상세: `docs/KJH/decisions/0003-two-copy-mcp-workflow.md`
