## 현재 국면

**기초 설계 확정 단계.** MINDHEXER(2폰 P2P **VR 침투 해킹 퍼즐**)의 게임 컨셉·조작 스킴·해킹 방식(펫 거미 + 점 패턴)·시각 언어까지 정리 완료. **은신·드론은 삭제.**

남은 큰 미결정: **6DoF 채택에 따른 SYB 통신 구조 변경 합의**(프로토콜 변경 요구 → 팀 합의 필수), **퍼즐 문법**, 개별 기믹(프레스·터렛·CCTV) 조종.

## 아직 안 정한 것

- **6DoF 채택을 SYB와 합의** — `InputPacket`에 Position 필드 추가(60→72바이트) + 컨트롤러 ARCore 스코프 (**최우선**)
- **유압프레스·터렛·CCTV 조종 방법**
- **릴레이 홉 제한 / 본체만 할 수 있는 것**
- **퍼즐 문법**(기믹 도입 순서)
- 수치 — 감지 범위·조준 n초·사거리·PD 게인·테두리 두께
- S24+ ARCore 지원 실기 확인, 6DoF 좌표 정렬, 진동↔ARCore 간섭
- 카드보드 스무스 이동 멀미 완화책
- 아트 방향 (발광 규율만 이식, 전체는 별도)

## 만드는 순서 (검증 우선)

1. **층 1만으로** 컨트롤러 → 헤드셋 자세 전송 + VR 안 큐브 회전. 지연·좌표계 해결
2. PD 제어로 로봇 손 조종 (층 1)
3. 해킹 그리드(SYB `HackGrid`) 연결 + 경비병 1 → **재미 판정**
4. 여기까지 되면 6DoF(층 2)를 얹는다 — ARCore, position 필드, 그립 설계
5. 카드보드 렌즈·하드보드지 마감

> 1~3(층 1)이 재미없으면 6DoF를 얹어도 무의미하다. 상세는 [design/기초_설계안.md](design/기초_설계안.md) §10.
