# VR 렌즈 튜닝 안내

> 뷰어(골판지/플라스틱 헤드셋)에 맞게 렌즈값을 맞추는 작업.
> **우리 게임 빌드로 하는 게 아니라 구글 웹 도구로 합니다.** 결과는 **URI 문자열 하나**입니다.

---

## 준비물

- **PC** (키보드 필요 — 값을 입력합니다)
- **S24+** (뷰어에 끼울 폰)
- **뷰어 실물**
- 자 (렌즈 간격 등을 잽니다)

---

## 순서

### 1. PC에서 도구를 엽니다

<https://wwgc.firebaseapp.com/>

### 2. 폼에 뷰어 치수를 입력합니다

- 렌즈 사이 거리
- 화면에서 렌즈까지 거리
- 트레이(폰 받침)에서 렌즈까지 거리
- 시야각, 왜곡 계수

> **S24+의 PPI 값이 필요합니다.** 도구가 정확한 PPI를 요구하니 미리 찾아 두십시오.

### 3. S24+를 3D 화면에 연결하고 뷰어에 끼웁니다

PC 화면에 나오는 **3D 뷰 주소**를 S24+ 브라우저로 엽니다. 폰을 뷰어에 끼웁니다.

### 4. 헤드셋을 쓴 채로 PC에서 값을 조절합니다

**PC에서 값을 바꾸면 헤드셋 안 화면이 실시간으로 바뀝니다.** (Firebase로 동기화됩니다)

혼자 하기 어려우면 둘이 하십시오 — 한 명은 쓰고, 한 명은 PC에서 조절.

### 5. 결과 URI를 복사합니다

맞춰지면 도구가 **Cardboard 기기 URI**를 줍니다.

```
https://google.com/cardboard/cfg?p=...
```

**이 문자열만 보내 주시면 됩니다.** QR 코드로도 뽑을 수 있는데, 우리는 문자열이면 충분합니다.

---

## 자주 막히는 곳

| 증상 | 확인 |
|---|---|
| 3D 화면이 폰에서 안 열림 | PC와 폰이 **같은 세션**에 붙었는지. 도구가 주는 주소를 그대로 열어야 합니다 |
| 값을 바꿔도 폰 화면이 그대로 | 동기화가 끊긴 것. 폰 쪽 페이지를 새로고침 |
| 어지럽거나 상이 겹침 | 렌즈 간격과 화면↔렌즈 거리가 제일 큽니다. 그 둘부터 |

---

## 우리 쪽에서 하는 일 (참고)

받은 URI를 `VrTuningData.cardboardProfileUri`에 넣습니다. 코드는 이미 그 값을 **우선 적용**하도록 되어 있어서 따로 고칠 게 없습니다.

```csharp
// CardboardProfile.Apply()
string uri = !string.IsNullOrEmpty(d.cardboardProfileUri) ? d.cardboardProfileUri : BuildUri(d);
```

---

## 왜 게임 안에 슬라이더를 안 만드나

Cardboard 플러그인이 왜곡·시야각·렌즈간격을 **기기 프로파일로만** 받습니다. 실시간 슬라이더를 지원하지 않습니다. 그래서 구글이 만든 이 도구가 표준 경로입니다.
