# docs/shared — 팀 합의 문서

셋(둘)이 **합의한 것만** 여기로 올라온다. 개인 공간([SYB/](../SYB/), [KJH/](../KJH/))의 초안이 검토·합의를 거치면 이곳으로 승격한다.

## 규칙

- 개인 폴더 = 각자 초안·작업 방식. 자유롭게 쓴다.
- `shared/` = **구현 기준이 되는 정본(SSOT)**. 여기 있는 것은 양쪽이 합의했고, 바꾸려면 다시 합의한다.
- 승격할 때 원본을 개인 폴더에서 지우지 않아도 된다. 다만 "지금 진실은 shared"임을 개인 README에 명시한다.
- 이미지 등 자산은 `shared/images/`.
