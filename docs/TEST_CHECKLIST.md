# 테스트 체크리스트

SPEC 5(안정성/예외) 및 6(일정)의 검증 항목을 실기기 기준으로 정리.

## 네트워크 전제 (매 테스트 전 확인)

- [ ] 두 폰이 **동일 로컬망** 또는 **S24+ 모바일 핫스팟**에 연결됨
- [ ] AP의 client isolation(단말 간 통신 차단)이 꺼져 있음
- [ ] 두 앱의 포트 설정이 `NetworkConstants`와 일치

## 1일차 — 최우선 마감 🔴

- [ ] **UDP Ping-Pong**: S10e → S24+ 패킷이 수신되고 시퀀스가 단조 증가
- [ ] Magic 불일치 패킷이 폐기됨
- [ ] Cardboard 스테레오 분할 렌더링이 실기기에서 정상

## 통신 기능

- [ ] 시퀀스 역전/중복 패킷 폐기 (SPEC 5.2)
- [ ] UDP 1초 미수신 시 S24+ UI 경고 표시 (SPEC 5.1)
- [ ] WebSocket 재연결 시도 동작 (SPEC 5.1)
- [ ] Discovery 브로드캐스트로 자동 페어링 성공
- [ ] 브로드캐스트 실패 시 **IP 직접 입력** 폴백으로 연결 (SPEC 2.3-3)
- [ ] S24+ 핫스팟 환경에서 코드 변경 없이 동일 동작 (SPEC 2.3-4)

## 입력/보간

- [ ] 터치 정규화 좌표 Lerp 보간으로 끊김 완화
- [ ] 자이로 쿼터니언 Slerp 보간
- [ ] 정규화 좌표 → 3x3 해킹 그리드 매핑 정확
- [ ] **역할 분리 확인**: 헤드트래킹은 S24+ 자체 센서만, S10e 자이로는 시점 회전에 영향 없음 (SPEC 5.5)

## 성능

- [ ] RTT 50ms 이내 (로컬 Wi-Fi/핫스팟) (SPEC 5.4)
- [ ] 패킷 유실 상황에서도 시각적 끊김이 허용 범위

## 게임플레이 (후반 일정)

- [ ] 해킹 패턴 판정 성공/실패가 WebSocket으로 S10e에 전달
- [ ] 적 AI(드론/터렛/CCTV) 비헤이비어 동작
- [ ] 암살 기믹 정상 트리거
- [ ] 배터리 경고 이벤트 표시

## 데모 리허설 (7일차)

- [ ] 콜드 스타트부터 페어링까지 60초 이내
- [ ] 연결 끊김 → 자동 복구 시연 가능
